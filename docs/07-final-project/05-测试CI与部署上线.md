## 5.1 测试设计：隔离是第一原则

`tests/conftest.py` 的核心：**测试永远不碰真实 books.db、不发网络请求**。

```mermaid
flowchart LR
    A["conftest 夹具"] --> B["tmp_path 建临时库<br/>建表 + 插 12 本样例书"]
    B --> C["dependency_overrides<br/>替换 get_db"]
    C --> D["TestClient(app)"]
    D --> E["14 个断言用例"]
```

```python
def override_get_db():
    c = sqlite3.connect(db_file)     # 临时库，跑完即删
    c.row_factory = sqlite3.Row
    try:
        yield c
    finally:
        c.close()

app.dependency_overrides[get_db] = override_get_db
with TestClient(app) as test_client:
    yield test_client
app.dependency_overrides.clear()
```

样例数据特意造得「有差异」：12 本书覆盖 5 个分类、全部 5 档评分、含 1 本缺货——让每个统计断言都有唯一确定值可验。

### 14 个用例覆盖什么

| 用例 | 验证点 |
|---|---|
| test_health | 健康检查 |
| test_summary | 汇总数值正确性（总数/分类数/库存拆分） |
| test_books_pagination | total 正确、分页不重不漏、id 升序 |
| test_books_filter_category_and_rating | 组合过滤精确命中 |
| test_books_search | 搜索不区分大小写 |
| test_books_param_validation | limit=500 → 422（参数校验生效） |
| test_book_detail_404 / found | 资源不存在与存在两条路径 |
| test_ratings_distribution | 评分分布精确值 {1:2, 2:1, 3:2, 4:3, 5:4} |
| test_price_histogram | 分桶边界与总数守恒 |
| test_categories_sorted_by_count | 排序正确 + 聚合值精确 |
| test_top_rated_length | 数量与排序 |
| test_charts_all_bundle | 聚合端点 7 组数据齐全 |
| test_docs_available | /docs 可用 |

真实运行结果：

```text
$ python -m pytest tests/ -q
14 passed, 2 warnings in 0.05s
```

测试写法的两个提醒：

- **断言精确值而非模糊存在**：`dist == {1:2, ...}` 远比 `assert len(dist) > 0` 有价值——它能在重构时抓住口径变化
- **警告要读**：本次输出的 StarletteDeprecationWarning 提示 TestClient 底层变化，升级前要关注

## 5.2 CI：push 即测试

仓库根 `.github/workflows/ci.yml`（语法讲解见 [GitHub Actions 章](../01-git-github/08-GitHub%20Actions持续集成入门.md)）：

```yaml
name: CI
on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ["3.13", "3.14"]    # 双版本矩阵
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}
          cache: pip
      - run: pip install fastapi==0.162.0 uvicorn==0.52.0 pydantic==2.13.4 pytest==9.2.0 httpx==0.28.1
      - run: python -m pytest tests/ -v
        working-directory: projects/book-insight
      - run: find projects -name "*.py" -not -path "*__pycache__*" -print0 | xargs -0 -n1 python -m py_compile
```

两步检查：接口测试 + **全仓库 .py 语法编译检查**（连实验代码也保证可导入）。CI 只装测试必需的轻量依赖，2 分钟内跑完。

## 5.3 部署上线：从空服务器到公网可访问

完整服务器准备（SSH 加固/UFW/venv）见 [Ubuntu 章系列](../02-linux-ubuntu/01-Ubuntu安装与远程连接.md)，这里给项目视角的最短路径：

### 第 1 步：取代码与环境

```bash
sudo apt update && sudo apt install -y python3-venv nginx
sudo git clone https://github.com/<your-username>/<your-repo>.git /opt/book-insight
cd /opt/book-insight/projects/book-insight
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

### 第 2 步：systemd 常驻服务

`/etc/systemd/system/bookinsight.service`：

```ini
[Unit]
Description=Book Insight FastAPI
After=network.target

[Service]
User=www-data
WorkingDirectory=/opt/book-insight/projects/book-insight
ExecStart=/opt/book-insight/projects/book-insight/.venv/bin/uvicorn api.main:app --host 127.0.0.1 --port 8000 --workers 2
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now bookinsight
curl -s http://127.0.0.1:8000/api/health     # {"status":"ok"}
```

要点：绑定 127.0.0.1（不直接暴露）、`Restart=on-failure` 自愈、日志用 `journalctl -u bookinsight -f` 查看。

### 第 3 步：Nginx 反向代理 + HTTPS

`/etc/nginx/sites-available/bookinsight`：

```nginx
server {
    listen 80;
    server_name <your-domain-or-ip>;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/bookinsight /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d <your-domain>     # 一键 HTTPS + 自动续期
```

### 第 4 步：数据更新流水线

```bash
cd /opt/book-insight/projects/book-insight && source .venv/bin/activate
git pull
python crawler/crawl_books.py        # 重新采集（可挂 cron/systemd timer）
python analysis/analyze.py           # 重新出图与 stats.json
sudo systemctl restart bookinsight   # 重启生效
```

## 常见坑与排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 502 Bad Gateway | uvicorn 没起来/端口不对 | `systemctl status bookinsight` + journalctl |
| certbot 失败 | 域名未解析到服务器 | 先 `dig <domain>` 确认 A 记录 |
| CI 里 pytest 找不到模块 | working-directory 没设置 | 参照 ci.yml 的写法 |
| 服务器上爬虫失败 | 无 Chrome（selenium 章节）/ 出网受限 | 本项目主爬虫只依赖 requests，检查出网与 DNS |
| 重启后大屏没数据 | data/books.db 权限 | www-data 对 data/ 有读权限 |
